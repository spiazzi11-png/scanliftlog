Save ScanLiftLog to your phone’s home screen for faster access at the gym. No App Store or Google Play download is required.

Open Gym Home Screen

iPhone / iPad

  1. Tap Open Gym Home Screen above (must open in Safari).
  2. On the gym page, tap the Share button
  3. Tap Add to Home Screen
  4. Tap Add

Add from the gym page so the icon opens Push Fitness Melville, not this help page.

Android

  1. Tap Open Gym Home Screen above
  2. Use the browser menu: Add to Home Screen or Install app
  3. Confirm the prompt if asked
